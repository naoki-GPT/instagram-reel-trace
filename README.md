# instagram-reel-trace

参考にするInstagramリール（URLか動画ファイル）と、人物＋お店の画像1枚から、自社撮影なしで同じ構成の縦型リールを作るスキル（版4.3）。

使い方と決まりは [SKILL.md](SKILL.md)、設計書の書き方は [references/design-yaml.md](references/design-yaml.md)。

**他の人に渡すときは、まず [START_HERE.md](START_HERE.md) を読んでもらう。** このリポジトリ自体が正本なので、ZIPなどで別にまとめ直さず、このリポジトリの場所をそのまま渡す（中身がいつでも照合できる形が、受け取った側のAIにも人にも安全）。

- 動画は MiniMax（`MINIMAX_API_KEY` が必要・有料）。確認は作る前の1回だけ。
- 参考の人が話しているカットは本人にセリフを話させる（話す型）。話していないカットは選んだ声を重ねる。
- フォントは Noto Sans JP・Anton（OFL）。
